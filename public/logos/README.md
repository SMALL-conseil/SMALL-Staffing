# Logos clients du reporting

Déposer ici les logos : un fichier par client, nommé d'après son nom en
minuscules sans accents ni espaces (tirets à la place) + `.png` :

    GROUPAMA        -> groupama.png
    PERNOD RICARD   -> pernod-ricard.png
    LBP             -> lbp.png

Format conseillé : PNG carré ≥ 88×88 px, fond transparent. Les parts les plus
grosses du donut affichent le logo automatiquement ; sans fichier, la pastille
de couleur suffit. (Le slug exact : lib/client-brand.ts → clientSlug.)
